 🍲 TastyBite - Ethiopian Food Menu

TastyBite is a responsive web project featuring an authentic Ethiopian restaurant landing page and menu showcase, built with pure HTML5 and CSS3.



 🚀 Features

- Header & Navigation: Simple, clean brand logo and section links.
- Hero Banner: Eye-catching introduction featuring Ethiopian cuisine branding.
- Popular Dishes Grid: Visual cards showcasing traditional dishes (Doro Wat, Shiro Wat, Kitfo, Tibs, Veggie Combo) with prices in Ethiopian Birr (ETB).
- Footer & Contact Info: Complete contact details, address, and social media links.
